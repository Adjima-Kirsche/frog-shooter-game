# Frog Shooter Mini Game (p5.js)

An interactive browser-based mini-game built with **JavaScript (p5.js)**, **HTML**, and **CSS** (400 × 600 px canvas). This project was developed under coding and UX/UI mentorship as a playable prototype for a university admissions portfolio in **UX/UI Design at Silpakorn University (SU), Thailand**.

## Live Demo
*(นำลิงก์ GitHub Pages มาวางตรงนี้ เช่น `https://adjima-kirsche.github.io/frog-shooter-game/`)*
## How to Play
- **Move Left / Right:** `←` / `→` Arrow keys
- **Shoot:** `Spacebar`
- **Restart (after Game Over):** `R` key
### Scoring & Rules
- **Black Bug:** `+1` point
- **Gold (Shiny) Bug:** `+5` points
- **Game Over Condition:** Missing `2` bugs (letting them fall to the ground) ends the game.
## Technologies & Concepts Used
- **Languages & Library:** JavaScript (`p5.js`), HTML5 Canvas, CSS
- **Programming Logic:** Conditional statements (`if / else`), Loops (`for`), Arrays, Keyboard Event Handling (`keyPressed`), and Collision Detection
- **UX/UI Focus:** Minimalist HUD layout, clear visual affordance (color-coded target rewards), and instant single-key replay flow
## Mentorship Role
Mentored the student through algorithmic thinking (flowchart design), core JavaScript game logic, UI state transitions (Gameplay vs. Game Over screens), and GitHub deployment to bridge visual design with functional interactive prototyping.
